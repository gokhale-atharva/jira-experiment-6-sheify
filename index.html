02 / HELP CENTRE

Quick answers

Where are my requests stored?

They stay in local browser storage. Clearing browser data removes them. Other browsers cannot see them.

Can I close a request?

Yes. Select Close request on an open request below. Its status changes to Closed.

Is this a real support service?

No. This is a software lifecycle experiment using Jira, GitHub and an automated pipeline.
